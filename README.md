# Video Archive Skill

通过与你的本地 AI 助手对话，完成视频分析、压缩方案选择、小样比较、批量压缩和原片归档。

适合希望为家庭录像、旅行记录或其他视频资料制作较小副本，又不想自己研究编码参数的使用者。AI 会结合素材和使用目标推荐方案；你看过小样、确认画质和处理范围后，才开始批量压缩。

本项目以 **Agent Skill** 的形式使用：将技能目录安装到 Codex 等能访问本地文件、执行终端命令的 AI 工具中，再通过对话操作。视频编码在你的电脑上完成，配套脚本不会上传视频。Skill 本身无需单独配置模型 API Key，AI 工具的登录与使用要求以该工具为准。

## 使用前需要准备什么

- **本地 AI 工具**：能够读取 Skill、访问你指定的文件夹并运行命令。只有聊天能力、无法访问本地文件的工具不能直接处理电脑中的视频。
- **运行环境**：Python 3.9+、FFmpeg 和 ffprobe。不确定是否已经安装也没关系，开始后 AI 会先检查，缺少工具时提供安装指导。
- **视频与存储位置**：准备原片目录，并选择压缩副本的保存位置。预留存放原片、小样和压缩副本的空间。

当前版本已在 **macOS** 验证；Linux 尚未验证，原生 Windows 暂不支持。其他 AI 客户端的安装与使用尚未实测。

## 安装

### 安装到 Codex

1. 下载上方的安装包，解压得到 `video-archive` 文件夹。
2. 将**整个文件夹**放入你的项目目录下的 `.agents/skills/`。没有这个目录时先创建它，最终应能找到 `.agents/skills/video-archive/SKILL.md`。请保留文件夹里的脚本和参考资料。
3. 在 Codex 中打开这个项目，使用下方的示例开始对话。如果技能未被发现，重启 Codex 后再试。

如果想在多个项目中使用，也可以将完整文件夹放入 `~/.agents/skills/`。项目安装和个人安装选一种即可；更新已有安装时，先比较版本，避免直接覆盖自己的修改。目录约定见 [Codex 官方技能说明](https://learn.chatgpt.com/docs/build-skills)。

### 使用其他本地 AI 工具

按该工具的 Agent Skills 安装说明放入完整的 `video-archive` 文件夹。若工具不能自动发现技能，可以明确让它读取其中的 `SKILL.md` 并遵循流程；它仍需具备本地文件访问和命令执行能力。不同客户端的支持情况请以实际检查结果为准。

### 直接使用源码仓库

如果你熟悉 Git，或者希望同时查看脚本与测试，可以克隆仓库：

```sh
git clone https://github.com/MelonTse/video-archive-skill.git
cd video-archive-skill
```

仓库已包含 `.agents/skills/video-archive/`，在 Codex 中打开仓库根目录即可使用，无需再复制一份 Skill。

## 第一次使用

安装后，可以把下面这段话发给 AI，并提供实际的视频目录：

> 使用 $video-archive 帮我压缩一批视频。先检查本地环境，缺少工具就指导我安装。分析视频后，询问我的用途和画质要求，推荐方案并制作小样。等我看过并确认后再批量处理，最后帮我整理压缩结果和原片。

你不需要事先知道合适的编码参数。AI 会根据分析结果与你确认用途、播放设备，以及画质、文件大小和处理时间的优先级。你也可以一开始就告诉它，例如：“主要在电视上看，优先保留画质，可以多花些时间压缩。”

## 使用流程

1. **检查环境**：确认压缩所需工具是否可用；缺少时指导安装，再重新检查。
2. **分析视频**：读取数量、体积、时长、分辨率、帧率和色彩等信息，列出无法读取或需要进一步确认的文件。
3. **明确目标与方案**：结合你的用途和播放设备，推荐可比较的压缩配置，说明画质、体积和耗时的取舍，同时确认原片如何保存。
4. **制作少量小样**：选择有代表性的片段，生成不同方案的样品供你对照观看。不满意时可以调整方案，再做小样。
5. **确认后批量处理**：你接受小样并同意本批处理范围后，按所选方案逐个压缩和校验。
6. **整理与归档**：汇总成功、失败和待复核的文件，说明压缩副本、原片和任务记录的位置，并指导后续保存。

批量处理支持后台运行、安全暂停和按文件续跑。安全暂停会先完成当前文件；尚未完成的视频恢复时需要从头编码。

## 完成后会得到什么

- **压缩副本**：保存到指定输出目录，并保留源目录的相对层级，便于查找对应视频。
- **处理结果**：包含逐文件的处理情况、容量变化，以及失败或待复核项目。
- **任务记录**：保存方案、小样、确认结果和执行状态，方便以后继续处理，或由另一个 AI 助手接手。

原片默认保留在原位置。你也可以选择在对应压缩副本校验成功后，将原片移到原目录下的归档子文件夹。脚本不提供删除原片功能，也不会覆盖已有输出。

由于原片仍然保留，生成压缩副本通常会增加当前磁盘的总占用；归档只是整理位置，不等于备份。任务记录中可能包含你的文件路径和文件名，请保存在本地，不要连同视频提交到公开仓库。

## 支持范围与限制

当前版本主要处理色彩标记完整的 **BT.709、H.264/HEVC、4:2:0** 视频，且每个文件只有一个主视频流。你不必自行判断这些技术条件，AI 会先扫描，再说明哪些视频可以处理。

- 保持分辨率、帧率、宽高比、方向和已知色彩信息，并复制全部音轨。HEVC 可保持原始 8-bit 或 10-bit；H.264 兼容方案仅支持 8-bit。
- 压缩副本不保留辅助数据、封面和章节。有字幕、多主视频流、未知色彩或其他不支持格式的文件需要单独复核。
- HDR（包括 HLG/PQ）及已知或疑似 Log 素材需要单独评估，当前流程不自动转换其色彩。如果拍摄时使用了 Log 模式，请主动告诉 AI。
- 暂不支持指定精确输出大小、缩放、调色、音频重编码和硬件编码。

压缩后的体积、画质和耗时因素材而异，小样用于帮助你选择，不能保证整批视频达到相同压缩率。自动校验会检查媒体结构、参数和时长等信息，但不包含全片解码或逐帧画质判断；请实际观看小样，并在常用设备上确认播放效果。

遇到环境或使用问题，可以提交 [Issue](https://github.com/MelonTse/video-archive-skill/issues)，附上操作系统、工具版本、操作步骤和报错信息，并移除日志中的私人路径等信息。已完成的测试和未验证事项见 [验证记录](VALIDATION.md)。

## 开发与测试

以下内容面向希望修改脚本或参与维护的贡献者，普通使用者无需执行。

运行脚本仅依赖 Python 标准库及系统中的 FFmpeg/ffprobe。FFmpeg 需包含所选的 `libx265` 或 `libx264` 编码器，并支持 `-fps_mode`；环境检查会确认这些能力。

在源码仓库中，使用已安装的 `uv` 创建独立开发环境并运行测试：

```sh
uv venv --python python3 .venv
.venv/bin/python -B -m unittest discover -s tests -v
```

测试使用临时目录和短合成视频，合成编码限制为一个线程。若使用 Skill 元数据验证器，另在开发环境安装 `PyYAML`；它不是压缩视频的运行依赖。参与修改前请阅读 [维护说明](AGENTS.md)。
